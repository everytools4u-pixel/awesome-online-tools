# Contributing to Awesome Free Online Tools

Thanks for your interest in contributing! This is a curated list of free online tools, and we welcome suggestions.

## How to Contribute

- **Add a tool:** Open an issue or pull request with the tool name, URL, and a short description.
- **Fix errors:** If a link is broken or a description is wrong, let us know.
- **Suggest improvements:** Better categorization, new sections — all welcome.

## Pull Request Guidelines

1. Fork this repository.
2. Create a new branch for your change.
3. Make your edit in the README.md (follow existing format).
4. Add a clear commit message.
5. Submit a PR against the `main` branch.
6. Ensure the tool is genuinely free, works in the browser, and respects privacy (prefer client‑side tools).

## Code of Conduct

Please read our [Code of Conduct](CODE_OF_CONDUCT.md). Be respectful and constructive.

For larger ideas, email us at [contact@toolimi.com](mailto:contact@toolimi.com).
